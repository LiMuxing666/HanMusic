## 本轮改动

- 正在播放页的大封面读取当前歌曲的本地 `artworkPath`，沿用已有封面缓存与圆角布局；按显示尺寸和设备像素比限制解码宽度，不增加原生 API 或依赖。
- 未提供封面、加载中、文件缺失或图片损坏时，显示原有默认图形。切歌时不保留上一首的图片，避免新歌曲暂时显示旧封面。
- 本地与在线歌曲均显示歌手和专辑，去除首尾空白后为空的字段分别显示“未知歌手”和“未知专辑”；长文本限制显示行数，并通过 Tooltip 提供完整内容。
- 保留本地歌曲文件名及完整路径提示，在线歌曲仍显示来源信息；继续使用窄窗口纵向、宽窗口横向布局。
