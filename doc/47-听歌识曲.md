# 听歌识曲

本轮未发布工作副本新增 Windows 听歌识曲，可识别电脑正在播放的声音或麦克风收到的音乐片段。需要用户自己的 AudD API Token、账户可用额度和网络连接；不内置免费无限识别服务，也不承诺识别哼唱或清唱。此前[设置与深色主题](46-设置与深色主题.md)的 649 项测试与实机记录不代表本轮识曲验证。

## 使用方式

1. 在侧栏打开“听歌识曲”。默认选择“电脑声音”，需要识别周围播放的音乐时改选“麦克风”。
2. 输入自己的 AudD API Token，点击“用于本次会话”。可在 [AudD 控制台](https://dashboard.audd.io/)获取和管理 Token 与账户额度；具体服务条件以 AudD 为准。
3. 播放要识别的音乐，确认页面的采样上传说明，再点击“开始识曲”。应用采样 12 秒，随后发送至 AudD 并显示识别结果。
4. 结果可复制歌名，或转到本地曲库、已配置的在线音乐源搜索。搜索不自动播放，也不会自动加入队列或歌单。没有匹配时可调整声音来源或换一段更清晰的音乐，再显式重试。

| 声音来源 | 采样内容与要求 |
| --- | --- |
| 电脑声音（默认） | Windows 当前默认输出设备的声音，可能包含同时播放的其他应用声音；不是仅录制 HanMusic 进程 |
| 麦克风 | Windows 当前默认麦克风的声音，需要可用设备和相应系统权限；请让音乐清晰可闻并避免混入说话声 |

无音频设备、无可用声音、麦克风访问失败、Token 无效、额度不足或网络失败时会显示中文提示。识别成功率取决于声音质量与服务端匹配结果，不保证每次都能识别。

## 采样、上传与取消

启动应用、打开识曲页、选择声音来源或配置 Token 都不会开始采样。只有显式点击“开始识曲”或“再试一次”才触发本次采样及上传；应用不后台持续监听。

采样在内存中生成 **12 秒、单声道 PCM16 WAV**，保留设备采样率，不写入本机音频文件。应用不建立识别录音档案，不把音频写入曲库、歌单或播放历史。音频会发送给 AudD，第三方服务的数据处理以其服务规则为准；本机不保存不等于第三方不接收或不处理。

点击“取消本次识别”、离开识曲页或退出应用会取消任务。取消期间不允许重新开始，等待采集停止后才能发起下一次；旧采样或旧网络请求的迟到结果不会覆盖新任务。取消前已经发出的音频无法撤回。重试需要再次点击，不自动重试网络识别请求。

Token 仅保留在本次应用会话中，退出后需要重新填写；可在空闲时更换或清除。输入去除首尾空白后，要求 **1–512 个可打印 ASCII 字符且不含空格**。Token 不进入状态文件、歌单或日志，输入框使用隐藏显示；本轮不提供 Token 持久保存。

## 实现范围

Windows 使用 WASAPI：电脑声音从默认播放端点以 loopback 模式采集，麦克风从默认录音端点采集。该方式与 Microsoft 的 [Loopback Recording](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording) 和 [Capturing a Stream](https://learn.microsoft.com/en-us/windows/win32/coreaudio/capturing-a-stream) 文档对应。当前不提供设备列表、指定其他应用进程或连续监听模式。

网络层按 [AudD 官方标准识别协议](https://docs.audd.io/)向固定 HTTPS 端点 `https://api.audd.io/` 发送 multipart POST，仅包含 `api_token` 与音频 `file`，不请求额外平台元数据。文件名固定为 `sample.wav`；产品只上传刚采集的片段，没有任意文件上传入口。

- 单次上传最多 **8 MiB**，网络请求整体限时 **30 秒**，响应最多 **1 MiB**。
- 不跟随重定向；取消、超时或关闭会中止对应请求。只返回经过校验的歌名、歌手、专辑、发行日期和安全歌曲链接字段，当前页面不提供自动打开歌曲链接的操作。
- `result: null` 表示没有匹配。服务端错误、无效响应和传输异常转为固定中文提示，不展示原始响应、Token 或底层异常正文。
- 应用状态仍为 **schema 5**；声音来源、Token 与识别结果均不新增持久化偏好。沿用已有依赖，未增加第三方包。
