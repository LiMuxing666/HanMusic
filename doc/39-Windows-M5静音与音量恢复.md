# Windows M5 静音与音量恢复（dev.23）

日期：2026-10-02。版本：`0.1.0-dev.23+23`。代码提交：`1ecb0ebb79fbe34b229477d88414284e1c2a003b`。M5 仍在进行中。

## 本轮改动

- 播放条的扬声器图标改为静音/恢复按钮，支持鼠标点击，以及 Tab 聚焦后按 Enter / Space 激活；按钮提示随当前音量切换。
- 静音将应用音量设为零，解除时恢复本次运行最近的非零音量；音量滑块调到非零也可解除静音。操作不改变播放状态、当前曲目或进度。
- 最近非零音量只在本次运行内记忆，不新增持久化字段。重启仍恢复既有保存音量；若保存为零且本次尚无非零音量记录，解除静音使用默认 70%。
- 复用既有音量提交与后端失败回滚，失败时保留错误提示；等待退出或关闭后拒绝新的音量操作。不增加音频后端或依赖。
