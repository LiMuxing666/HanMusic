# Windows M5 静音与音量恢复（dev.23）

日期：2026-10-02。版本：`0.1.0-dev.23+23`。代码提交待记录。M5 仍在进行中。

## 本轮改动

- 播放条的扬声器图标改为静音/恢复按钮，支持鼠标点击，以及 Tab 聚焦后按 Enter / Space 激活；按钮提示随当前音量切换。
- 静音将应用音量设为零，解除时恢复本次运行最近的非零音量；音量滑块调到非零也可解除静音。操作不改变播放状态、当前曲目或进度。
- 最近非零音量只在本次运行内记忆，不新增持久化字段。重启仍恢复既有保存音量；若保存为零且本次尚无非零音量记录，解除静音使用默认 70%。
- 复用既有音量提交与后端失败回滚，失败时保留错误提示；等待退出或关闭后拒绝新的音量操作。不增加音频后端或依赖。

## 验证与交付

- **4 项定向检查通过**：两项控制器场景覆盖默认恢复、静音前音量、滑块解除、失败回滚/重试及退出保护；两项页面场景覆盖有/无曲库布局的鼠标和 Tab / Space 操作，并确认播放状态、曲目和进度不变。
- 页面检查采用 800×600 / 200% 字号，按钮和滑块可达。首轮 3/4 通过，失败源于测试主动取消页面 FocusScope 后无法重新进入；改用真实鼠标点击后 Tab 遍历，两个页面场景复跑通过，没有绕过键盘遍历。
- 改动文件定向静态分析、格式、差异检查与只读 review 通过。
- 正常 `lib/main.dart` Windows Release 构建与完整 ZIP 待生成，源码提交、包大小、SHA-256 和构建清单待记录。
- 开发机完整包检查待执行；本轮不将框架测试视为真实音频输出或系统交互通过。
- 本轮未运行全量回归或性能采集。

包的启动与手工验收步骤见[预览说明](./12-Windows预览运行与验收.md)。
