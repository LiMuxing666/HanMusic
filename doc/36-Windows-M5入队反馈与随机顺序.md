# Windows M5 入队反馈与随机顺序（dev.20）

日期：2026-10-02。版本：`0.1.0-dev.20+20`。M5 仍在进行中。

## 本轮改动

- 本地曲库菜单和在线结果使用统一入队反馈：显示新增、已存在或暂不可加入。提示位于播放条上方，包含“查看队列”和关闭入口；连续操作只保留最新一条，切换页面时收起，不自动消失或自动播放。
- 重复加入不再触发队列更新、选择变化或清空随机播放候选；只有真正加入新歌时才执行原有队列更新逻辑。
- 曲库菜单提交时重新核对当前索引，已移除或刚标记缺失的曲目不能通过旧菜单加入；退出待处理时拒绝入队。实际不可用不会误报为已存在。
- 提示限制两行并可悬停查看完整内容，保留键盘操作与无障碍通知。

## 验证与交付

- 4 项服务检查：空队列/释放后不可用、正常去重、重复加入保持唯一剩余随机曲目且不通知队列、空队列加入仅建立暂停就绪态。
- 1 项控制器检查：旧歌曲对象不能绕过缺失/移除/退出保护，恢复可用后采用当前索引元数据，重复加入不播放。
- 2 项页面检查：本地/在线新增与重复反馈、提示替换与关闭、查看队列、切页收起及零音频加载。本地使用 800×600 / 200% 字号及长曲名，提示、队列入口和播放按钮均可达。
- 以上 **7 项定向检查通过**，改动文件静态分析通过。首轮本地测试在滚动后未等待布局就点击菜单，补齐等待和命中断言后单项复跑通过；服务及在线结果未重复运行。未跑全量或性能测试。

完整开发预览包信息将在构建完成后补入。
