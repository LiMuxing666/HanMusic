# Windows M5 队列当前歌曲定位（dev.25）

日期：2026-10-02。版本：`0.1.0-dev.25+25`。代码提交待记录。M5 仍在进行中。

## 本轮改动

- 队列工具栏新增“定位当前歌曲”图标按钮，支持鼠标点击，以及 Tab 聚焦后按 Enter / Space 激活。
- 按当前歌曲 ID 查找最新队列索引，将该行滚动到视口中央附近；首尾位置限制在可滚动边界内，依据当前字号对应的行高计算位置。
- 定位只滚动列表，不触发播放、进度跳转或队列修改。切歌不会自动跟随滚动，保留用户正在浏览的位置。
- 无当前歌曲、当前歌曲不在队列或清空处理中时禁用。触发时先取消拖拽，下一帧使用最新索引与布局；切页释放后不操作旧列表。不增加依赖或持久化字段。

## 验证与交付

- **3 项定向检查通过**：100 首队列中尾部/中部歌曲定位，800×600 / 200% 字号下鼠标及 Tab / Space 操作；同帧重排、删除前序项、清空与切页释放；既有普通拖拽重排回归。
- 定位后当前行完整可见或居中，播放、进度和队列保持，定位本身没有调用音频后端。无当前项及清空确认期间按钮禁用。
- 改动文件定向静态分析、格式、差异检查与只读 review 通过。拖拽中定位的取消路径已定点审查，真实 Windows 混合输入仍待实机复核。
- 正常 `lib/main.dart` Windows Release 构建与完整 ZIP 待生成，源码提交、包大小、SHA-256 和构建清单待记录。
- 开发机完整包检查待执行；框架中的滚动与字号检查不代表真实 Windows 键鼠或系统缩放验收通过。
- 本轮未运行全量回归或性能采集。

包的启动与手工验收步骤见[预览说明](./12-Windows预览运行与验收.md)。

真实 Windows 窗口中的鼠标/键盘定位、队列拖拽、系统缩放及切页交互仍需实机复核。框架测试不能替代原生系统交互、实际音频及正常关窗验收。
