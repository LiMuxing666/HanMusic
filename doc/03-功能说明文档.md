# HanMusic 功能说明文档

> 版本：v0.1（初稿）　　日期：2026-09-28
> 状态：功能设计阶段，代码尚未实现
> 关联文档：[01-技术架构要求](./01-技术架构要求.md)、[02-需求文档](./02-需求文档.md)

本文档描述各功能模块的详细行为规则，作为开发与验收依据。每个功能按「功能描述 / 主要流程 / 规则与边界 / 异常处理」组织。

---

## 1. 应用框架与导航

**页面结构**（底部导航，移动端；桌面端为侧边栏，布局自适应、组件复用）：

| Tab | 页面 | 内容 |
|---|---|---|
| 1 | 本地音乐 | 本地曲库列表（歌曲/专辑分组视图）、导入入口、搜索 |
| 2 | 在线音乐 | 网络源状态、在线搜索与结果列表 |
| 3 | 设置 | 主题、网络源配置、定时默认项、数据管理 |

**全局常驻**：
- **迷你播放条**：除播放页外所有页面底部悬浮，展示封面/曲名/播放按钮，点击进入播放页，支持上下切歌，可上滑展开播放页。
- **播放页**：大封面、标题/歌手、进度条（可拖拽）、播放控制（上一首/播放暂停/下一首/播放模式）、音量、定时入口、加入歌单入口。

## 2. F1 本地音乐库

**功能描述**：将用户选择的本地音频文件（mp3/flac/m4a/wav/ogg/aac 等）导入 App 曲库，提供浏览、搜索、播放入口。

**主要流程**：
1. 用户点击「导入文件」或「导入文件夹」→ 唤起系统文件选择器（`file_picker`）；
2. App 校验所选文件扩展名，读取元数据（标题/艺术家/专辑/时长/内嵌封面，读取失败以文件名兜底）；
3. 生成 `Song` 记录（来源标记 `local`）写入本地曲库索引并持久化；
4. 曲库列表按「歌曲 / 专辑 / 添加时间」分组展示，顶部提供关键字搜索（匹配标题/艺术家/专辑）。

**规则与边界**：
- 同一文件路径重复导入时跳过并提示，不产生重复记录；
- 大文件夹导入显示进度，导入过程可取消；列表实时增量刷新；
- 支持长按/右键多选删除（仅从曲库移除索引，不删除源文件，删除前二次确认）；
- 启动时对曲库做存在性校验：源文件已不存在的条目标灰并提示，不参与随机/顺序自动播放。

**异常处理**：元数据读取失败 → 文件名兜底，不阻断导入；无读取权限 → 引导去授权，不闪退。

## 3. F2 网络音乐源播放

**功能描述**：用户在设置中配置自定义网络音乐源（API 地址），即可在「在线音乐」页搜索歌曲并串流播放，与本地歌曲共用同一播放器。

**主要流程**：
1. 设置 → 网络源：填写 API Base URL（保存时做连通性探测）；
2. 在线音乐页输入关键字 → 调用源的搜索接口 → 结果列表（标题/歌手/来源标记）；
3. 点击结果 → 调用源的取播放地址接口 → 拿到流媒体 URL → 交给 `PlayerService` 播放；
4. 在线歌曲可加入播放队列/歌单/收藏，与本地歌曲同构存储（`Song.source = online`）。

**规则与边界**：
- 网络源接口形态以配置描述（搜索路径、取地址路径、字段映射），不硬编码任何第三方平台；
- 在线歌曲的封面/时长等信息缺失时优雅降级显示；
- 搜索请求做防抖（约 500ms）与结果序校验（旧请求晚到不覆盖新结果）；
- 未配置网络源时，在线页显示引导态（跳转设置）。

**异常处理**：网络超时/接口错误 → Toast 明确提示（超时、无法连接源、未找到可播放地址）；播放地址失效 → 提示后自动跳过到队列下一曲（可设置关闭）。

## 4. F3 播放器核心

**功能描述**：统一播放器，支撑本地文件与网络流两类来源，提供完整播放控制、后台播放与系统媒体中心集成。

**播放队列与模式**：
- 队列：任意位置「播放」即以该列表为队列，从点击项开始；播放页可查看并拖动调整当前队列、删除单项；
- 播放模式：顺序播放、列表循环、单曲循环、随机播放，切换后持久记忆；
- 模式行为：顺序播放至队尾自然停止；随机播放保证不与上一首重复（队列 ≥ 2 时）。

**播放控制**：播放/暂停、上一首/下一首、进度拖拽（显示缓冲态）、音量调节（含与系统音量联动策略：桌面为 App 音量，移动端跟随系统）。

**后台与系统集成**：
- Android：后台前台服务持续播放，通知栏显示封面/标题/控制按钮，锁屏可控；
- 桌面：窗口最小化持续播放；
- 音频焦点（audio_session）：来电/其他应用抢占 → 自动暂停；拔出耳机 → 自动暂停；被打断结束后不自动恢复（用户手动续播）。

**持久化**：退出 App 后记忆上次队列、当前曲目、进度与播放模式，下次启动恢复（不自动播放，停留在就绪态）。

**异常处理**：文件损坏/不存在 → 提示并自动跳下一曲；网络流断开 → 自动重连一次，失败则提示。

## 5. F4 定时功能（睡眠定时器）

**功能描述**：设定倒计时，到点自动暂停/停止播放，服务睡前场景。入口位于播放页与通知区快捷操作。

**主要流程**：
1. 播放页点击「定时」图标 → 弹出定时面板；
2. 选择：预设时长（15 / 30 / 60 / 90 分钟）/ 自定义分钟数 / 「播完当前歌曲后停止」；
3. 启动后：播放页与迷你条定时图标高亮并显示剩余时间（倒计时分钟级刷新）；
4. 到点：执行暂停（不清空队列与进度），面板提示「定时已停止播放」；
5. 再次进入面板可取消、更换时长，或「顺延 10 分钟」。

**规则与边界**：
- 同时只允许存在一个定时任务，新设定覆盖旧任务；
- 「播完当前歌曲」与倒计时互斥，二选一；
- 定时与播放器解耦：定时器只负责到点发出「暂停」指令，即使当前无播放也不报错；
- 应用被系统杀死后定时失效（可接受，首次使用时在面板内小字说明）。

**异常处理**：无任何播放行为时启动定时 → 允许（到点静默结束）；设备休眠不影响倒计时准确性（按墙钟时间计算而非累计 tick）。

---

## 6. F5 播放队列与歌单

**歌单**：
- 自建歌单：新建（命名）、重命名、删除（二次确认，不删除歌曲本身）；
- 添加歌曲：本地/在线/播放队列均可加入歌单；同一歌单内重复添加给出去重提示；
- 歌单详情：列表展示、批量播放（设为队列）、单曲移除、排序（拖拽）；
- 内置「我喜欢的音乐」默认歌单，收藏心形按钮一键加入/移除。

**队列**：见 F3；支持「收藏当前歌曲」快捷操作。

---

## 7. F6 播放历史

- 每次实际开始播放（进入播放态 ≥ 10s）记录一条：歌曲、来源、时间；
- 历史页按时间倒序展示、去重合并展示「最近播放」，支持清空（二次确认）；
- 点击历史项即以该歌曲建立队列播放。

---

## 8. F7 应用设置

| 设置项 | 行为 |
|---|---|
| 主题 | 跟随系统 / 浅色 / 深色，即时生效并持久化 |
| 网络源 | API 地址配置、连通性测试、清除；仅存本地 |
| 播放失败自动跳过 | 开/关（默认开） |
| 数据管理 | 曲库索引/历史/歌单占用展示与一键清空（逐项二次确认） |
| 关于 | 版本号、开源许可说明 |

---

## 9. 通用体验要求（全功能适用）

1. **加载态**：所有列表有 loading 占位；**空态**：曲库/歌单/历史/搜索结果为空时给引导文案与操作按钮（如「去导入本地音乐」）；
2. **错误态**：失败页面提供「重试」；
3. **反馈**：操作结果用轻量 Toast/SnackBar；破坏性操作（删除/清空）一律二次确认；
4. **国际化**：文案集中管理，预留中英双语切换能力（MVP 先中文）；
5. **无障碍**：主要按钮提供语义标签，支持系统字号缩放。
