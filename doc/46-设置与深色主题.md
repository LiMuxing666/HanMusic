# 设置与深色主题

本轮在未发布的 Windows 工作副本增加设置页、深色主题和排序记忆。本文记录实现与 2026-10-29 的验证结果；[播放历史与批量歌单](45-播放历史与批量歌单.md)中的 schema 4、622 项测试及实机结果保留为上一轮证据。

## 入口与外观

侧栏点击“设置”进入设置页。设置页可滚动，按外观、曲库、播放、数据与保存、关于 HanMusic 分区。

| 主题 | 行为 |
| --- | --- |
| 浅色 | 固定使用浅色界面，不随系统深色模式改变 |
| 深色 | 固定使用深色界面 |
| 跟随系统 | 根据系统当前浅色或深色模式显示，并响应系统外观变化 |

新建数据与 schema 1–4 旧数据升级后默认使用浅色，保留原有外观。主题选择立即生效，成功保存后重启恢复。自动测试验证切换主题保持播放会话、当前歌曲和所选页面；实机验证浅色切换为深色后仍停在原进度，重启恢复深色。

## 曲库排序与播放

设置页可选择导入顺序、歌曲名称、歌手或专辑，并用“降序排列”开关切换方向。这里与曲库工具栏共享排序偏好：任一入口的修改会同步到另一处，成功保存后重启恢复。默认值是导入顺序、升序。排序只调整曲库视图，不重排原始曲库索引或已经建立的播放队列；后续“播放全部”和入队仍按当前搜索、排序后的结果执行。

“播放失败时自动跳过”与现有队列中的开关共用 `PlayerService.skipOnError`，没有新增另一份设置。关闭后保留失败歌曲，用户可重试或手动切歌。该值沿用原播放状态的保存方式；启动恢复音量和进度后仍保持暂停。

## 数据、保存与恢复默认

“数据与保存”显示当前曲库歌曲数、队列歌曲数、歌单份数和历史歌曲数；歌单数包含内置“我喜欢”，历史数是保留的歌曲条数，并非累计播放次数。

正式文件存储下显示 `FileAppStateStore.directory.path`，即本次实际使用的数据目录。路径支持选择文字和“复制目录路径”；复制失败会显示提示。此处不假定固定安装路径，配置 `HANMUSIC_DATA_DIR` 后显示的是对应实际目录。源音频继续保存在原位置。

设置变更会触发现有自动保存；点击“立即保存”会等待设置与当前播放状态一起保存，成功后显示“设置与播放状态已保存。”。失败时显示重试提示，已有存储警告也在页面展示；失败不会被当作已保存。保存期间相关操作禁用，页面卸载或退出操作使旧异步反馈失效。正常退出继续沿用等待保存及失败后取消退出的流程。

“恢复显示默认设置”需要确认，取消后保留现状。确认仅恢复以下三项：

- 主题：浅色。
- 曲库排序：导入顺序。
- 排序方向：升序。

恢复显示默认不会清除曲库、队列、歌单、历史或音频文件，也不改变失败跳过开关、音量、播放模式和播放位置。恢复后的偏好继续通过自动保存或“立即保存”写入。

## 关于与组件许可

“关于 HanMusic”显示 `0.1.0-rc.2+28 · 开发工作副本`，尚未发布新的发行版本。“查看组件许可”打开 Flutter 的许可页面，范围是 Flutter 收集的组件许可。

这一入口不能证明原生音频库、其他分发材料或完整发行许可已经齐备；既有授权和分发核验边界继续以[Windows 依赖与分发检查](11-Windows依赖与分发检查.md)及随包材料为准。

## 状态格式与兼容

应用状态写入版本升级为 **schema 5**，新增 `settings` 对象：

```json
{
  "themeMode": "light",
  "librarySort": "importOrder",
  "librarySortDescending": false
}
```

`themeMode` 允许 `light`、`dark`、`system`；`librarySort` 允许 `importOrder`、`title`、`artist`、`album`；`librarySortDescending` 必须是布尔值。schema 5 要求完整有效的设置对象，缺字段、类型错误、非法枚举或额外设置字段均视为无效快照，沿用有效备份恢复规则。

schema 1–4 继续可读，统一使用浅色、导入顺序、升序作为设置默认值；已支持版本中的曲库、队列、歌单、历史和播放状态按原迁移规则保留。下一次成功保存写入 schema 5。保存排队前捕获设置快照；没有注入设置服务的旧工具会保留此前已存设置，避免写成默认值。

发现 schema 6 或更高版本时保留原文件并进入只读保护，不使用旧备份降级覆盖；主文件与备份都无效时也停止保存并显示警告。数据目录锁、串行写入、有效备份与退出保存机制沿用现有实现。HanMusic JSON 歌单交换文件仍使用独立格式版本 `1`，不随应用状态 schema 升级。
