# Windows M5 播放失败重试（dev.24）

日期：2026-10-02。版本：`0.1.0-dev.24+24`。代码提交待记录。M5 仍在进行中。

## 本轮改动

- 当前歌曲加载失败后，错误提示提供“重试播放”，底部播放按钮也可重试；关闭错误提示后仍保留底部入口。
- 重试重新加载当前歌曲并从头播放，在线歌曲重新获取播放地址；保留队列顺序和播放模式，继续遵循播放失败自动跳过设置。
- 触发前按稳定歌曲 ID 复核最新队列。加载中、歌曲已移除或标记缺失、等待退出、控制器关闭以及过期 ID 均不触发重播，避免旧提示重新播放错误歌曲。
- 重试入口针对歌曲加载失败。正常音量、进度调整等其他错误保持既有处理，不因提示错误而将当前歌曲从头重播。不增加依赖或持久化字段。

## 验证与交付

- **4 项定向检查通过**：在线解析首次失败后重试取得新地址，重排后的混合队列与模式保留；重复、过期、缺失、移除及退出/关闭保护；有/无曲库两种布局的错误按钮与关闭提示后 Tab / Space 重试。
- 页面检查采用 800×600 / 200% 字号，错误提示和播放按钮可达；成功后恢复播放，普通音量/导入错误不显示重试入口。只读 review 确认失败期间进度条保持禁用。
- 改动文件定向静态分析、格式、差异检查与只读 review 通过。测试新增的一处缺少大括号的风格提示已修正。
- 正常 `lib/main.dart` Windows Release 构建与完整 ZIP 待生成，源码提交、包大小、SHA-256 和构建清单待记录。
- 开发机完整包检查待执行；框架测试不代表真实音频输出或系统交互通过。
- 本轮未运行全量回归或性能采集。

包的启动与手工验收步骤见[预览说明](./12-Windows预览运行与验收.md)。

## 验收边界

真实 Windows 窗口中的失败提示、鼠标/键盘重试、本地和在线歌曲恢复出声、正常关窗仍需实机复核。服务和框架测试不能替代实际音频、原生系统及正常关窗验收。

万曲性能、实际出声、真实休眠、系统缩放、干净机和发行条件仍按[开发计划](./05-Windows版本开发计划.md)保留；dev.24 仍为开发预览，M5 尚未完成。
