# Windows M5 搜索快捷键与清空（dev.19）

日期：2026-10-02。版本：`0.1.0-dev.19+19`。本轮补齐本地与在线搜索的键鼠交互，M5 仍在进行中。

## 本轮改动

- 本地曲库和在线音乐页面使用统一搜索组件。Ctrl+F 聚焦并选中已有关键词，初始无输入焦点、焦点在播放条时也可使用；不作用于正在播放/队列页面，也不抢占弹窗输入。
- 非空搜索显示清空按钮；输入框内 Esc 同样清除，并保持输入焦点。本地恢复完整曲库，在线复用原有 `setQuery('')` 取消防抖/请求并清空结果，迟到响应不回填。
- 外部查询状态变化同步到文本框。正常输入不重置相同文本的选区与输入法组合状态；文本和焦点资源随组件释放。

## 验证与交付

- 两项新增搜索 Widget 场景通过，覆盖 Ctrl+F 全选、Esc/按钮清空、查询同步、弹窗焦点和在线迟到响应隔离。本地场景还覆盖初始焦点和播放条焦点。
- 两项原有键盘翻页场景通过，分别为 1280×720 / 100% 字号和 800×600 / 200% 字号；共 **4/4**，未运行全量回归或性能采集。
- 改动文件定向 `dart analyze` 无问题，格式检查通过。初轮发现失焦后 Ctrl+F 无响应，调整主页面焦点作用域后复跑通过；本地场景另外修正了主动取消整个初始 scope 焦点的测试操作，分别验证启动时 Ctrl+F 和输入框失焦后的 Ctrl+F。

完整开发预览包信息将在本轮构建完成后补入。

## 验收边界

Widget 检查覆盖框架输入与状态行为，不能代替 Windows 原生键盘、中文输入法和真实窗口复核。万曲性能、物理出声、最小化/恢复/正常关闭、真实休眠、系统缩放、干净机和发行条件仍按[开发计划](./05-Windows版本开发计划.md)保留；本轮不将开发预览标记为正式 v0.1。
