> 版本：v0.1（初稿）　　日期：2026-09-28

> 关联文档：[01-技术架构要求](./01-技术架构要求.md)、[03-功能说明文档](./03-功能说明文档.md)

## 1. 项目背景与目标

**背景**：现有音乐类产品普遍存在"在线曲库绑定单一平台、本地文件管理弱"的问题。用户（含开发者本人场景）需要一个轻量、无广告、可自控的音乐播放器：既能管理本地音乐文件，又能接入自选的网络音乐源播放。

**项目目标**：打造一款基于 Flutter 的跨平台音乐播放 App（暂定名 **HanMusic**），以最小依赖实现"本地曲库管理 + 网络源播放 + 定时播放控制"三大核心能力，界面简洁、代码可复用易读。

**非目标（本期不做）**：
- 不做音乐上传/云同步、社交、评论等社区功能；
- 不内置任何版权音源或破解源，网络源由用户自行配置；
- 不做歌词逐行卡拉OK渲染、均衡器等高级音频特性（列入远期池）。

---

## 2. 目标用户与使用场景

| 用户画像 | 典型场景 |
|---|---|
| 本地音乐收藏者 | 手机/电脑里存有一批 mp3/flac 等音频文件，希望统一导入、分类浏览、连续播放 |
| 自有网络源用户 | 搭建或订阅了私人音乐 API（如自建服务），希望在 App 内搜索并直接串流播放 |
| 助眠听歌用户 | 睡前听歌，希望定时自动停止播放，不必起床关音乐 |

---

## 3. 平台范围

| 平台 | 优先级 | 说明 |
|---|---|---|
| Android | P0 | 主要使用场景，需支持后台播放与通知栏控制 |
| Windows | P0 | 桌面主要使用场景 |
| iOS / macOS | P1 | 随架构兼容，按需验证发布 |
| Linux | P2 | 架构兼容即可 |
| Web | P2 | 受浏览器限制（自动播放策略、文件访问），允许功能降级 |

## 4. 功能需求总览

| 编号 | 功能模块 | 优先级 | 简述 |
|---|---|---|---|
| F1 | 本地音乐库 | P0 | 导入本地音频文件/目录，生成曲库，支持浏览与搜索 |
| F2 | 网络音乐源播放 | P0 | 配置自定义网络源，搜索在线歌曲并串流播放 |
| F3 | 播放器核心 | P0 | 播放/暂停/切歌/进度/音量/播放模式，后台播放与锁屏控制 |
| F4 | 定时功能 | P0 | 睡眠定时器：倒计时暂停/停止、"播完当前歌曲后停止" |
| F5 | 播放队列与歌单 | P1 | 当前播放队列管理；自建歌单、收藏 |
| F6 | 播放历史 | P2 | 记录最近播放，支持一键回放 |
| F7 | 应用设置 | P1 | 主题（亮/暗）、网络源配置、数据清理 |
| F8 | 多端适配 | P0 | 六端可构建，核心端（Android/Windows）体验完整 |

> 各功能的详细交互与边界规则见 [03-功能说明文档](./03-功能说明文档.md)。

## 5. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 万级本地曲库列表滚动不卡顿（虚拟列表）；播放起播时间本地 < 1s、网络 < 3s |
| 稳定性 | 播放中断（来电、拔耳机、网络断开）有明确行为定义与恢复策略；崩溃率趋近 0 |
| 可维护性 | 严格 MVVM 分层，依赖极简；新页面接入成本 ≤ 半天 |
| 可移植性 | 业务代码平台无关，平台差异收敛在适配层 |
| 隐私安全 | 所有数据仅存本地；网络源地址由用户配置，不上传任何用户数据 |
| 存储 | 曲库索引、设置持久化本地，重装后可通过重新导入恢复 |

## 6. 约束与假设

1. 技术栈约束：Flutter + GetX + MVVM，依赖引入遵循"极简"原则（见架构文档选型表）。
2. 网络源假设：网络音乐源遵循"可搜索、可获取播放地址"的最简 API 形态，具体接口由用户在设置中配置；App 不内置商业平台 API。
3. 权限假设：Android 需要音频文件读取权限；桌面端通过系统文件选择器授权访问。
4. 后台播放以 Android 为一等公民，桌面端保持窗口常驻即可满足。

## 8. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 第三方播放库在桌面端兼容性不足 | Windows/Linux 播放异常 | 播放器以接口抽象，可切换 media_kit 等实现，业务层不动 |
| 网络源接口形态多样 | 对接失败 | 源配置化 + 统一 Song 模型 + 明确错误提示，不支持的字段优雅降级 |
| GetX 社区维护活跃度 | 长期升级风险 | GetX 用法收敛（状态/路由/注入三大件），封装层薄，必要时可低成本替换 |
| 后台播放被系统杀死 | Android 定时/播放中断 | 文档说明行为边界，提示用户电池白名单设置 |
