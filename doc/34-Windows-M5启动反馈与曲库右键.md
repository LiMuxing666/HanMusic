# Windows M5 启动反馈与曲库右键（dev.18）

日期：2026-10-02。代码提交：`b4ab25480182056c7124aeed7c13c07dc6b63cd2`。本轮产物是 Windows x64 开发预览包，M5 尚未验收完成。

## 本轮改动

- 生产入口先运行独立的 `StartupLoadingApp`，提供启动等待的可见反馈；等待首帧最多 500 ms，随后仍按原顺序加载数据目录与应用状态，失败时进入原有失败页。这改善的是等待期间的反馈，**没有证明启动速度提高**；慢盘和屏幕关闭场景尚未实测。
- 曲库歌曲行在鼠标右键位置打开菜单，复用行尾省略号的操作与选择处理。缺失曲目不能加入播放队列，但仍可从曲库移除；原有左键与键盘操作保留。真实鼠标菜单位置和缺失文件场景仍需在 Windows 窗口复核。
