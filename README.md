# HanMusic

基于 Flutter 的音乐播放器项目，计划提供本地曲库、自定义网络源播放与睡眠定时。

当前在 `Windows_lmx` 分支推进 Windows x64 版本，已实现本地曲库、播放队列、完整睡眠定时和 M4 自定义网络源核心：多文件/目录导入、元数据和封面、搜索、四种播放模式、本地状态恢复，以及通用 JSON 源配置、在线搜索和串流播放。当前正在执行 M5 Windows MVP 验收，应用版本为 `0.1.0-dev.20+20`；系统交互、真实休眠和正式发行条件尚未全部完成。

导入文件或文件夹只加入曲库，点击歌曲后按当前搜索结果建立队列并播放；取消选择保留原状态。曲库支持搜索标题、歌手和专辑，缺失文件灰显，移除索引保留源文件。队列可重排、删除，支持顺序、列表循环、单曲循环和随机模式；播放失败自动跳过可关闭。

Windows 启动时会先显示加载提示，再恢复曲库与播放状态。本地歌曲行支持右键打开操作菜单；缺失文件仍可从曲库移除，但不能加入播放队列。

本地曲库和在线音乐页面支持 Ctrl+F 聚焦并选中搜索关键词。搜索框内按 Esc 或点击清空按钮即可清除搜索；在线清空会取消待处理请求，迟到结果不会重新出现。弹窗内的输入不受页面搜索快捷键影响。

从曲库或在线结果加入队列后，播放条上方会显示新增或已存在提示，可直接查看队列或关闭提示。连续操作只保留最新一条；加入队列不会自动开始播放，重复加入也不会重置随机播放的剩余顺序。

元数据在后台读取，失败或超时后以文件名兜底。封面仅接收受大小和尺寸限制的 PNG/JPEG，超限或缓存失败使用默认图形。重启恢复曲库、队列、当前曲目、进度、模式、音量和跳过设置，保持暂停；用户点击播放后才加载音频。

睡眠定时支持 15/30/60/90 分钟、自定义 1–1440 分钟、播完当前歌曲停止，以及在原截止时间上顺延 10 分钟。新设定替换旧任务；按曲结束模式遇到手动切歌或删除当前项会取消。到期暂停并保留队列与位置，优先于自动切歌和单曲循环；退出后不恢复旧定时。

状态以带版本的本地 JSON 保存，保留有效备份。遇到不支持的新版本数据，或主文件与备份均损坏时，保留原文件并进入只读保护，本次更改不会保存。本机通过 `HANMUSIC_DATA_DIR=D:\dev\data\HanMusic` 将状态与封面缓存放在 D 盘；未配置绝对路径时使用系统应用支持目录。

Windows 启动时先独占数据目录，防止多个实例覆盖同一份状态；不同数据目录可独立运行。退出时等待保存，保存失败可返回播放器或明确选择仍然退出；音频或清理操作有界等待，目录锁一直保留到进程终止。

在线音乐支持匿名 HTTP(S) JSON GET 源，可配置搜索、分页、字段映射和取播放地址接口。源添加/编辑需先通过连接测试；500ms 搜索防抖，切源后丢弃旧响应。本地与在线歌曲共用队列，在线项只保存源 ID 和歌曲 ID，每次加载重新取地址；地址加载失败最多重新解析一次，连续失败会停止。暂不支持登录、API Key、自定义 Header 或商业平台私有协议。

运行 `dart run tool/online_fixture_server.dart` 启动本地测试源，然后在“在线音乐”中添加网络源、粘贴 [样例 JSON](doc/examples/online-source.local.json)，以 `test` 测试并保存后搜索播放。完整复现和错误样例见 [网络源协议](doc/09-Windows网络源协议.md)。源配置独立保存在应用数据目录的 `online` 子目录。

## Windows 开发

当前验证基线为 Flutter 3.41.9 / Dart 3.11.5，配合 Visual Studio C++ 桌面工具链。构建工程使用不含中文的路径；本机通过 `D:\project\HanMusic` 目录入口访问原项目。

配置 SDK、Pub 缓存和与锁文件一致的依赖源后，在项目目录运行：

```powershell
flutter pub get --enforce-lockfile
flutter analyze --no-pub lib test tool
flutter test --no-pub
flutter build windows --release --no-pub
```

Release 输出为 `build/windows/x64/runner/Release`；运行时保留整个目录，不仅复制 EXE。本机开发者模式、符号链接和原生插件构建已通过验证。其他机器需完成对应环境配置，详见环境文档。

`tool/windows_*_probe.dart` 是独立诊断入口，不是正常应用入口；运行诊断后重新执行默认 Release 构建。当前交付为 Windows 播放器开发预览，尚未完成干净机器分发和 M5 发行验收。

`tool/package_windows_preview.ps1` 每次从干净的 Release 目录重建 `lib/main.dart`，输出完整开发预览 ZIP、展开的 Flutter 通知、补充许可材料和逐文件 SHA-256。默认输出 `D:\dev\releases\HanMusic`；使用包内 `Start-HanMusic.cmd` 时数据位于包旁 `UserData`。预览包尚未通过对外发行条件核验，不会自动上传 GitHub Release。

dev.11 启动器在创建数据目录前检查实际 VC++ DLL 的 x64 架构和版本；缺失或过旧会提示 Microsoft 官方安装链接。最低版本随本次构建工具链写入 `RUNTIME-REQUIREMENTS.json`，检查器不下载、安装或修改系统运行库；通过检查仍需进行干净 Windows 的完整功能验收。
